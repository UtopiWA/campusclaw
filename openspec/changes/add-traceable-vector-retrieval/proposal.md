# Proposal

## Why

CampusClaw 已能按班级安全保存教学材料，但师生仍需逐份打开文件才能定位内容，也无法判断回答依据来自哪份材料。第二次迭代需要在不削弱现有会话、角色和班级边界的前提下，把已入库正文变成可检索、可回溯且在无依据时不会编造的知识能力。

## What Changes

- 新增独立的知识切片模型和索引状态，将 `knowledge_entries.body_text` 按自动窗口、自定义参数或 Markdown 标题层级切分；原文保持不变，教师可为本班材料显式重建索引。
- 新增 MySQL 中文全文索引与 Qdrant 向量索引。正文和摘录只保存在 MySQL，Qdrant 只保存向量与班级、材料、知识条目和切片编号。
- 新增 `keyword`、`vector`、`hybrid` 三种本班检索模式；混合模式在两路各自过滤后用 RRF 合并名次，默认使用混合模式。
- 新增可追溯检索 API，命中结果包含材料标题、切片序号、字符范围、摘录和材料入口；空查询、外部依赖故障、无命中和跨班请求具有明确且不泄露数据的响应。
- 新增 `POST /api/ask`：先取本班混合检索前 4 条，只有存在可靠切片时才调用服务端对话网关并返回顺序一致的引用；无依据时返回固定句子且不调用模型。
- 将讲义上传调整为“先持久化、后异步解析与索引”：HTTP 201 在材料文件安全提交后立即返回 `PENDING`，后台任务再解析知识条目并建立索引，页面通过材料状态反馈处理中、就绪或失败。
- 在现有 Vue `AppShell` 和设计令牌上将知识检索页改为类似 GPT 网页端的连续对话布局，保留直接检索入口；回答引用按本次结果顺序从 1 编号并直接展示片段，不暴露切片序号或内部 Chunk ID 作为引用编号。
- 扩展 Docker Compose、服务端配置、`.env.example` 和 README，加入仅供后端访问的 Qdrant、嵌入网关与对话网关配置，并补充索引重建和验收说明。
- 将 README 中“本学期不做检索问答”的旧边界更新为本次已纳入的可追溯检索与受限问答范围。

## Capabilities

### New Capabilities

- `knowledge-retrieval`: 覆盖材料切分与重建、MySQL/Qdrant 双索引、关键字/向量/混合检索、服务端班级隔离、可追溯结果、无依据短路、受限问答、前端检索体验和外部依赖故障语义。

### Modified Capabilities

- `auth-upload`：保留认证、班级隔离、原文件原子保存、查看和下载契约；将知识正文解析从上传请求事务移到提交后的有界后台任务，并通过现有索引状态暴露处理结果。

## Impact

- 后端新增切分、索引、检索、RRF、Qdrant、嵌入网关和对话网关模块，以及面向检索和问答的 REST API；继续使用 Java 17、Spring Boot 3、Spring Security 和 Spring Data JPA。
- Flyway 新增 `knowledge_chunks`、索引状态、外键和 MySQL ngram 全文索引；现有材料及知识条目需支持幂等补索引，删除材料时同步清理对应向量。
- Compose 从 frontend、backend、mysql 扩展为包含内部 Qdrant 服务及持久化卷；Qdrant 与两个模型网关不得作为浏览器入口，密钥只能由后端环境变量读取。
- 前端新增连续对话消息区、底部输入器、直接检索模式及顺序引用组件，并复用当前共享应用壳、认证状态和 API 工具。
- 测试范围扩展到三种切分、阈值与 RRF、索引重建、嵌入失败、Qdrant 故障降级、问答短路、教师/学生权限以及 MySQL/Qdrant 双重班级过滤。
- 本变更不移除现有 API；材料上传成功后立即返回已持久化材料，后台解析或嵌入失败时保留原文件并标记失败，失败内容不参与检索且可重试。

## Non-goals

- 不实现流式输出、开放式长对话、模型自主调用工具或在无检索依据时凭训练记忆回答。
- 不引入消息队列、分布式任务平台或跨节点任务协调；异步解析使用单实例内有界执行器，并由启动补偿恢复未完成材料。
- 不实现交叉编码器重排、语义分句、父子切片、增量差异嵌入或分数学习；首版固定使用课件规定的阈值和 RRF 参数。
- 不引入 LangChain、LlamaIndex、Dify、Go 服务或新的前端主题，保持当前 Vue + Spring Boot 架构。
- 不把正文复制进 Qdrant，不向浏览器暴露 Qdrant、嵌入/对话网关、密钥、原始向量或服务端存储路径。
- 不新增 PDF、Office、图片和音视频解析，不改变现有 `.txt`/`.md` 上传范围。
- 不重做账号、角色、材料文件生命周期、多校多租户、生产级高可用或完整 CI/CD。
